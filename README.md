# Greenways organization guidance

This repository is the connector-visible entry point for work across the
`greenways-ai` organization. GitHub repository content, issues, pull requests,
native relationships, checks, and canonical GitHub links are authoritative.
GitHub Projects visualize that state; they are not required context for an
agent to understand or execute an issue.

Start here:

- [Repository catalog](docs/repository-catalog.md)
- [Connector-first delivery workflow](docs/connector-first-delivery.md)
- [Transparency contract](docs/transparency.md)
- [Greenways Infra](https://github.com/orgs/greenways-ai/projects/2)
- [Greenways OS](https://github.com/orgs/greenways-ai/projects/3)
- [Rollout authority](https://github.com/greenways-ai/workspace/issues/26)

The files under `.github/` provide default issue and pull-request contracts for
Greenways repositories that do not define a repository-specific override.
